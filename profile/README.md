## 🇺🇸 Our Mission

Computer Science has incredible books, papers and open-source projects. Unfortunately, much of this knowledge is available only in English or is difficult for beginners to digest.

**Cs-Brazil exists to bridge that gap.**

We don't translate books. We don't copy documentation. Instead, we study, understand and create **original educational content** that helps more people learn Computer Science through clear explanations, practical examples and real-world projects.

We believe that one of the best ways to truly master a subject is to explain it to someone else.

---

## 🇧🇷 Nossa Missão

A Ciência da Computação possui livros, artigos e projetos incríveis. Grande parte desse conhecimento, porém, está disponível apenas em inglês ou é difícil para quem está começando.

**A Cs-Brazil nasceu para diminuir essa distância.**

Nós não traduzimos livros. Nós não copiamos documentação. Nós estudamos o assunto e produzimos conteúdo **autoral**, didático e voltado para quem quer realmente entender como as coisas funcionam.

Acreditamos que explicar um assunto é uma das melhores formas de aprendê-lo.

---

## 🚀 Os Três Pilares

Toda contribuição da comunidade se encaixa em pelo menos um destes pilares.

### 📚 1. Livros

Alguns dos melhores livros de Ciência da Computação nunca foram publicados em português. Nosso objetivo não é traduzi-los — é estudá-los e explicar seus conceitos usando nossas próprias palavras.

Cada capítulo se transforma em um material didático contendo:

- explicações autorais
- analogias
- exemplos próprios
- exercícios
- diário de estudo

### 🛤️ 2. Trilhas de Aprendizado

Nem todo mundo precisa estudar um livro inteiro. Às vezes o objetivo é aprender apenas o necessário para resolver um problema específico. As trilhas organizam esse caminho.

**Exemplos:**

- Linux para DevOps
- Git para iniciantes
- Redes para Back-end
- Matemática para Machine Learning

Cada trilha reúne diferentes referências em um único percurso organizado.

### 🛠️ 3. Projetos Reais

Uma das formas mais eficientes de aprender engenharia de software é lendo código de verdade. Na Cs-Brazil estudamos projetos reais, próprios ou open source (respeitando suas licenças), explicando:

- arquitetura
- organização do código
- decisões técnicas
- erros encontrados
- melhorias possíveis

Nosso objetivo é transformar software real em material didático.

## 🤖 "Mas uma IA já faz isso..."

Ferramentas de IA conseguem explicar conceitos rapidamente, e nós também as utilizamos como apoio. Mas aprender não acontece apenas lendo uma resposta pronta.

Na Cs-Brazil você encontra:

- experiências de quem realmente estudou o assunto
- analogias criadas durante o aprendizado
- erros encontrados no caminho
- discussões técnicas
- código validado e executado
- revisões humanas

A IA pode acelerar o estudo. Mas compreender um assunto continua sendo uma atividade humana.

## 📓 Diário de Estudo

Aprender envolve muito mais do que acertar. Por isso incentivamos cada colaborador a manter um **Diário de Estudo**.

O diário registra:

- onde você travou
- quais dúvidas apareceram
- o que pesquisou além da referência
- quais analogias ajudaram
- quais erros cometeu
- o que faria diferente hoje

Esses registros ajudam outras pessoas que provavelmente passarão pelas mesmas dificuldades. Mais detalhes em `docs/learning.md`.

---

## 📝 Exercícios

Sempre que possível, cada capítulo ou projeto deve possuir exercícios. Mais importante do que responder corretamente é explicar o raciocínio utilizado.

> A resposta mostra **o resultado**. O raciocínio mostra **como pensar**.

## 🤝 Como Contribuir

Existem várias formas de participar da comunidade. Você pode:

- escrever um capítulo
- criar uma trilha
- documentar um projeto
- revisar conteúdo
- melhorar documentação
- abrir Issues
- responder dúvidas

Antes de iniciar um trabalho grande, abra uma Issue para evitar esforços duplicados. Consulte `CONTRIBUTING.md`.
